Please download the code "github.rar" directly. The code of paper "Multimodal Remote Sensing Image Matching Considering Structural Saliency".

This code is written in C#. If you only use this code for image matching, you only need to run the RMSS.exe file in the " RMSS\RMSS\bin\x64\Debug\g" directory. If you need to change the code, please use the Visual Studio platform (I am using Visual Studio2019). The code uses the RMSS algorithm (paper: Multimodal Remote Sensing Image Matching Considering Structural Saliency). The comparison of RMSS with seven state-of-the-art algorithms using six types of multimodal remote sensing images as experimental data demonstrates that the RMSS is simple to implement, exhibits high robustness to rotation in multimodal images, and can substantially improve the number and localization accuracy of matching points and the correct matching rate.
